# PlantPal

PlantPal is a plant-care app that helps people keep their houseplants alive by tracking each plant and reminding them when it needs water.

## Who is it for?

Busy city plant owners: people with a handful of houseplants in an apartment who love having them but keep forgetting which plant needs water and when.

## What problem does it solve?

Most houseplants don't die from lack of love, they die from missed or irregular watering. People lose track of which plant was watered last, and different plants need different schedules. PlantPal solves this by keeping all plants in one place, giving each a watering schedule, and sending a reminder when it's time.

## Features

**Plant Management**
- Add a plant
- View my plant list
- Edit or delete a plant
- Search my plants
- Upload a plant photo

**Care & Reminders**
- Set a watering schedule
- See today's watering tasks
- Mark a plant as watered
- Receive a reminder notification

## How the project is organized

This is a course project for Software Processes (Software Engineering, 2026/27). The focus is the process, not the code.

- **Jira project:** key `SP`, Scrum board with 2 sprints. Work is split into epics, user stories, tasks and bugs.
- **Branches:** one branch per ticket, named with the ticket key, e.g. `SP-12-setup-repo`.
- **Commits:** every commit message starts with the ticket key, e.g. `SP-12 set up repo and README`.
- **Pull Requests:** every ticket is merged into `main` through a Pull Request with the ticket key in the title. No direct commits to `main` after the first one.
- **Jira + GitHub:** connected with the GitHub for Jira app, so branches and PRs show up on each ticket.
